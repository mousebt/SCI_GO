# 参考文献目录

本目录用于保存“大语言模型构建虚拟标准化病人”课题申报书相关文献。

## 子目录

- `pdfs/`：已下载全文 PDF。
- `metadata/`：PMID、DOI、RIS、BibTeX、EndNote、题录表等。
- `search-strategies/`：PubMed、Web of Science、Scopus、Google Scholar 等检索式与检索记录。
- `notes/`：精读笔记、摘要翻译、证据摘录、引用用途说明。

## 使用规则

- 下载的论文 PDF 优先放入 `pdfs/`。
- 批量检索结果放入 `metadata/`，保留检索日期和数据库来源。
- 每一条关键引用最好在 `notes/` 中说明“支撑标书哪一段主张”。
- 不确定真实性或未读全文的文献，不直接写入正文作为确定依据。
