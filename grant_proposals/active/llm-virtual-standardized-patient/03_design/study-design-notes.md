# 研究设计草案

## 可选设计路线

### 路线 A：构建与评价研究

构建虚拟标准化病人系统，邀请专家评价真实性、教学适配性、安全性和反馈质量。

### 路线 B：教学干预试点

将虚拟标准化病人用于某一课程或培训模块，比较使用前后学习者表现、满意度、自我效能或 OSCE 评分。

### 路线 C：混合方法研究

结合系统构建、专家 Delphi/共识评价、学习者试用数据和访谈，形成可推广的教学应用框架。

## 初步推荐

[VERIFY] 若申报教学改革或院级课题，优先采用“构建与评价 + 小规模教学试点”的混合路线，风险较低，也更容易形成明确成果。

## 4 篇已下载文献后的设计修订

基于 4 篇正文研读，推荐将课题设计调整为：

`需求分析 -> 护理场景蓝图 -> LLM 辅助生成案例 -> 护理专家审核 -> 虚拟标准化病人交互系统 -> 可用性测试 -> 教学干预试点 -> 混合评价`

### 推荐任务包

1. 需求分析：访谈护理学生、护理教师和临床带教老师，明确护患沟通/健康评估训练中的场景需求、风险和功能边界。
2. 案例库构建：建立护理虚拟标准化病人元数据，包括年龄、性别、疾病场景、护理问题、沟通难点、情绪状态、评分要点。
3. 系统构建：采用病例知识库、角色画像、对话记忆、错误纠正和反馈生成模块，避免单一 LLM 直接扮演病人。
4. 效果评价：结合自评量表、OSCE/教师评分、对话日志分析和访谈，评价临床沟通能力、健康评估能力、AI 准备度、使用体验和安全边界。

### 推荐评价指标

- 系统层面：事实一致性、护理知识准确性、误导率、角色一致性、交互延迟、反馈可操作性。
- 学习者层面：自评临床能力、护患沟通能力、健康评估能力、AI 准备度、学习满意度。
- 教学层面：OSCE/教师评分、案例适配度、教师工作负担、课程整合可行性。
- 风险层面：隐私保护、知识错误、过度依赖、伦理接受度、持续使用意愿。
