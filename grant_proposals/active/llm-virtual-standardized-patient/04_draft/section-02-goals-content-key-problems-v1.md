# 二、研究目标、研究内容和拟解决的关键问题

## （一）总体目标

本课题拟面向护理本科生/实习前护生在护患沟通与健康评估训练中的学习需求，构建基于大语言模型的护理虚拟标准化病人案例库与交互原型，形成“护理场景蓝图—大语言模型辅助生成—护理专家审核—虚拟病人交互—训练反馈—教学评价”的闭环流程，并通过教学试点评价其在提升学习者沟通能力、健康评估能力、AI 准备度和学习体验方面的应用价值。

本课题的核心目标不是开发一个通用问答机器人，而是构建一种可嵌入护理教学流程、可由教师监管、可被专家审核、可进行效果评价的虚拟标准化病人训练工具，为护理教育中的情境化训练和形成性评价提供可复制方案。

## （二）具体研究目标

### 1. 构建护理虚拟标准化病人场景蓝图与案例库

围绕护患沟通、健康评估、入院评估、慢病宣教、急症识别和 OSCE 训练等护理教学场景，建立虚拟标准化病人案例元数据框架。每个案例拟包括患者基本信息、疾病或健康问题背景、护理评估重点、沟通难点、情绪状态、学习目标、学生任务、标准化应答边界、评分要点和反馈规则。

预期形成一套可扩展、可审核、可复用的护理虚拟标准化病人案例蓝图，为后续系统构建和教学应用提供内容基础。

### 2. 建立大语言模型辅助生成与护理专家审核机制

基于案例蓝图，利用大语言模型生成虚拟病人的病例初稿、角色画像、对话规则、情绪表现和反馈文本，并组织护理教育专家、临床带教老师和课程教师从专业准确性、护理适配性、角色真实性、教学价值和伦理安全性等方面进行审核。

该目标重点解决大语言模型生成内容可能存在的病例重复、场景不真实、护理任务不明确、知识错误和反馈误导等问题，使虚拟标准化病人的生成过程从“自动生成”转变为“人机协同构建”。

### 3. 构建护理虚拟标准化病人交互与反馈原型

在经专家审核的案例库基础上，构建虚拟标准化病人交互原型。系统拟包括病例知识库、角色画像、对话记忆、问题识别、安全边界和反馈生成等模块，使学习者能够围绕特定护理情境与虚拟病人开展多轮互动。

系统训练结束后，应能够根据学习者的对话过程，从信息采集完整性、沟通表达、情绪回应、健康评估重点、护理判断和遗漏问题等方面生成反馈，为学生自我反思和教师形成性评价提供依据。

### 4. 评价虚拟标准化病人在护理教学中的应用效果与边界

将虚拟标准化病人应用于护患沟通、健康评估或 OSCE 训练场景，采用量化与质性相结合的方法评价其教学效果、系统可用性和风险边界。量化评价拟关注学生自评临床能力、沟通能力、健康评估能力、AI 准备度、学习满意度和系统可用性；客观或半客观评价拟包括教师评分、专家盲评、OSCE 表现评分、对话日志质量和任务完成度；质性评价拟关注学生和教师对系统真实性、反馈价值、学习负担、信任和持续使用意愿的看法。

该目标重点验证本系统作为护理教学辅助工具的可用性、有效性和可推广条件，同时明确其不能替代真人标准化病人、教师指导和真实临床接触的边界。

## （三）研究内容

### 1. 护理教学场景与功能需求分析

本研究首先围绕护理学生在护患沟通和健康评估训练中的学习困难开展需求分析。拟通过半结构式访谈、焦点小组或问卷调查，收集护理学生、护理教师和临床带教老师对虚拟标准化病人的场景需求、功能需求、反馈需求和风险顾虑。

重点分析以下问题：

1. 现有护患沟通、健康评估或 OSCE 训练中，学生最缺乏哪些练习机会；
2. 哪些护理场景最适合转化为虚拟标准化病人训练任务；
3. 学生希望系统提供何种反馈，教师希望系统支持何种评价；
4. 使用大语言模型虚拟病人可能带来哪些知识、伦理、隐私和依赖风险。

该部分结果将用于确定案例库范围、系统功能边界和教学评价指标。

### 2. 护理虚拟标准化病人案例库构建

根据需求分析结果和护理课程目标，建立护理虚拟标准化病人案例蓝图。案例库拟优先选择具有训练价值和可评价性的典型场景，如入院护理评估、慢病患者健康宣教、急性症状识别、患者焦虑情绪沟通、术前/术后护理宣教、文化敏感性沟通等。

每个案例的构建流程包括：

1. 明确教学目标和学生任务；
2. 设定患者基本信息、疾病背景和护理问题；
3. 设计患者情绪、沟通风格和配合程度；
4. 设置学生必须识别或询问的关键评估点；
5. 制定虚拟病人可回答、不可回答和需安全提示的边界；
6. 形成评分要点和训练后反馈规则；
7. 经护理专家审核后定稿。

该研究内容将形成可追溯的案例开发流程，避免大语言模型无审核地批量生成病例。

### 3. 大语言模型虚拟标准化病人交互原型构建

在案例库基础上，构建虚拟标准化病人交互原型。系统功能不追求复杂平台化开发，而优先保证教学可用性和安全可控性。初步功能包括：

1. 病例知识库：保存经审核的病例信息、护理评估要点、标准化回答和反馈规则；
2. 角色画像：控制虚拟病人的年龄、性别、病情、情绪、语言风格和配合程度；
3. 对话记忆：记录学生已经询问的信息，维持多轮对话一致性；
4. 安全边界：限制系统输出未经审核的诊疗建议、错误护理判断或隐私敏感内容；
5. 反馈生成：根据学生表现生成结构化反馈，提示已完成内容、遗漏要点和改进建议；
6. 日志记录：保存训练过程中的对话记录，用于教师评价和研究分析。

该部分将形成可试用的虚拟标准化病人原型，并通过专家评价和小范围可用性测试进行修订。

### 4. 教学试点与应用评价

将虚拟标准化病人嵌入护理教学训练环节，开展小规模教学试点。根据申报单位课程安排，可选择单组前后测、准实验设计或交叉设计。试点流程包括课前说明、虚拟病人训练、训练后反馈、教师点评和学习者反思。

评价内容包括：

1. 学生层面：临床沟通信心、健康评估能力、自评临床能力、AI 准备度、学习满意度；
2. 表现层面：OSCE 或情境任务评分、关键评估点覆盖率、对话完整性、教师/专家评分；
3. 系统层面：回答准确性、角色一致性、反馈可操作性、交互稳定性、错误或误导性回答；
4. 接受度层面：学生和教师对真实性、易用性、信任、持续使用意愿和课程整合可行性的评价；
5. 风险层面：隐私保护、知识错误、过度依赖、伦理接受度和教师监管需求。

该部分结果将用于判断虚拟标准化病人是否适合作为护理教学中的补充训练工具，以及后续推广需要满足的条件。

## （四）拟解决的关键问题

### 1. 护理场景如何前置，而不是让护理停留在应用讨论中

现有大语言模型医学教育应用常以通用问诊或患者问答为主，护理教育特异性不足。本课题拟从护理课程目标和护患沟通训练需求出发，将护理评估、护理诊断、健康宣教、情绪支持和护理伦理边界前置到案例库和系统设计中，解决虚拟病人“像患者，但不像护理教学对象”的问题。

### 2. 如何保证虚拟标准化病人内容真实、准确、可审核

大语言模型生成病例时可能出现代表性不足、重复模式、知识错误或情节不合理。本课题拟通过案例蓝图、专家审核、知识库约束和迭代修订流程，建立可追溯的内容质量控制机制，解决虚拟病人生成过程不可控的问题。

### 3. 如何提升虚拟病人的多轮互动稳定性和角色一致性

虚拟标准化病人需要在多轮对话中保持病史、情绪、沟通风格和信息披露节奏的一致性。本课题拟通过角色画像、对话记忆、标准化应答边界和安全提示，减少角色漂移、前后矛盾和误导性回答。

### 4. 如何建立同时覆盖技术质量和教学效果的评价体系

如果仅评价学生满意度或使用体验，难以说明虚拟标准化病人的教学价值。本课题拟同时评价系统质量、学生表现、教师评分、对话日志和学生/教师体验，形成更完整的评价体系。

### 5. 如何明确虚拟标准化病人的应用边界和伦理治理要求

大语言模型虚拟病人可作为课前预演、课后巩固和形成性评价工具，但不能替代教师指导、真人标准化病人和真实临床接触。本课题拟在系统设计和教学应用中明确教师监管、数据脱敏、知情同意、错误纠正和隐私保护要求，保证技术应用边界清楚、风险可控。
