# 把新论文的现有材料放在这里

你可以直接把文件或整个文件夹拖进本目录，不需要预先分类或改名。支持混合放入：

- 已有 Word、Markdown、LaTeX 稿件
- 中文研究笔记、实验记录、方法说明
- Excel/CSV 结果表与统计输出
- 图片、图注、绘图源文件
- PDF 文献、BibTeX/RIS/EndNote 导出文件
- 目标期刊指南、投稿模板
- 审稿意见、旧版本和合作者批注

放好后，只需对我说：

> START_HERE 材料已放好，请盘点材料并启动论文。

## 我会怎样处理

1. 只读盘点文件并计算校验值。
2. 判断材料属于一篇还是多篇论文。
3. 给出材料分类、论文类型和缺失信息报告。
4. 创建 `papers/<论文ID>/` 独立工作区。
5. 将材料复制到对应目录并记录来源，不立即删除这里的原件。
6. 建立一句话论证、主张—证据表和术语表。
7. 请你确认核心主张、证据和边界后开始正文撰写。

## 默认分类

| 材料 | 进入论文目录 |
|---|---|
| 已有正文、提纲、草稿 | `03_manuscript/source/` |
| 数据表、统计结果、实验结果 | `02_evidence/source-data/` |
| 方法、实验方案、代码说明 | `02_evidence/methods-source/` |
| 图片、图注、绘图源文件 | `04_figures/source/` |
| PDF 文献、文献库和检索记录 | `05_references/source/` |
| 合作者意见、审稿意见和回复 | `06_review/source/` |
| 期刊指南、投稿模板和投稿材料 | `07_submission/source/` |
| 暂时无法判断的材料 | `00_admin/unclassified/` |

原始材料默认不会被 Git 自动提交，避免大文件、敏感数据或未发表材料意外进入版本库。
