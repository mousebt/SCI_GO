# 论文启动模式

每篇论文必须在 `paper.yaml` 中记录 `start_mode`。允许值只有三个：

- `auto`：根据接收材料自动判断；判断不可靠时向用户确认。
- `existing_zh_manuscript`：从已经写好的中文论文出发，改造成符合 SCI 投稿逻辑的英文稿。
- `materials_from_scratch`：从实验材料、数据、图片和笔记出发，从零构建论文。

模式只决定启动路径，不降低证据、引用、术语和人工确认标准。

## 模式 A：existing_zh_manuscript

适用于已有较完整中文论文、学位论文章节、中文期刊稿或成体系中文初稿。

处理顺序：

1. 冻结中文原稿为来源材料，不直接覆盖。
2. 提取事实命题、数据、引用、术语和研究边界。
3. 诊断论文类型、章节职能、段落逻辑和主张—证据缺口。
4. 给出“保留 / 重组 / 补证据 / 删除或降级”的结构审计。
5. 按目标期刊重建英文提纲并由用户确认。
6. 先改造 Results，再处理 Introduction、Conclusion、Title、Discussion、Methods，最后写 Abstract。
7. 英文稿翻译研究意图而非逐句翻译；不得改变数字、统计意义或因果强度。

该模式的目标是“保真重构”，不是语言替换。原中文稿中的结构问题不能被流畅英文掩盖。

## 模式 B：materials_from_scratch

适用于只有实验数据、图表、方法、研究笔记、文献和零散段落，尚无完整论文。

处理顺序：

1. 盘点材料并识别论文边界。
2. 建立主张—证据表和术语账本。
3. 形成一句话论证与研究论文论证链。
4. 暴露缺失的证据、比较、边界和引用，不自行补造。
5. 设计章节及段落职能并由用户确认。
6. 从 Results 开始写作，再完成 Introduction 与 Conclusion、Title、Discussion、Methods，最后写 Abstract。

## auto 判断规则

满足以下大部分条件时选择 `existing_zh_manuscript`：存在连续中文稿，且包含研究问题、方法、结果以及讨论/结论中的至少三类内容。

以下情况选择 `materials_from_scratch`：材料以数据、图片、实验记录、文献和零散笔记为主，或现有文字不足以形成可审计的完整论证。

若一份学位论文包含多个可拆分研究，应先确认论文边界，不能把整本学位论文直接当作一篇 SCI 稿件处理。
