# Initial question

Direction ID: `contrast-adverse-reaction-nursing-no-faers`

Title: 造影剂临床不良反应与护理研究（不使用FAERS）

## Initial framing

- Problem: 本院造影剂相关不良反应记录过短，缺少具体造影剂、时间、生命体征、处置、转归和事件链，难以支持复核、交接和再次暴露管理。
- Population/setting: 接受增强CT或其他含碘造影检查的成人患者，以及承担观察、处置和记录的影像护理人员。
- Possible data: 本院全部造影检查台账、造影剂不良反应登记、护理记录、处置记录、过敏史/再次暴露记录；当前已知材料为44例简短登记和约9,500次服务量背景，但检查级数据尚未核实。
- Possible method: 回顾性记录质量审计；专家共识建立最小字段集；前后对照的质量改进或实施研究；必要时加入护士可用性和工作负荷评价。
- Possible article type: documentation audit、quality improvement、implementation study 或 nursing informatics validation。
- Target reader: 影像护理、护理信息学、患者安全及医院质量改进团队。
- Boundary: 不使用FAERS作为主要证据；不把服务量当作发生率分母；不证明护理干预降低临床不良反应，除非存在预设对照和结局数据。
