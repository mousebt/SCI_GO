# 近 2 年“护理前置 + 用药安全/药物警戒”研究证据检索

检索日期：2026-07-16  
时间范围：2024-07-16 至 2026-07-16  
主要数据库：PubMed  
问题：如果把“护理”放在研究设计前台，而不是把护理作为背景词，近 2 年是否已有相似研究？

## 一句话结论

有，而且数量不小；但近 2 年的成熟路径主要不是“FAERS + 护理”，而是三类更护理前置的设计：

1. 护士 ADR/药物警戒上报行为、障碍与干预；
2. 护士给药错误、近失事件、给药安全能力与报告意愿；
3. 护士主导的用药监测、随访、撤药或特定药物安全管理。

因此，若我们的研究要突出护理学科贡献，更稳妥的主轴应是“护理流程/护士行为/护士主导监测 + 用药安全结局”，FAERS 或其他公开药物警戒数据库更适合作为补充证据或背景比较，而不宜直接作为唯一主轴。

## 本次“护理前置”的判定标准

本次没有把所有出现 nurse/nursing 的文章都算作护理前置。较严格的护理前置包括以下任一情况：

- 题名中直接出现 nurse / nurses / nursing，且研究对象与用药安全、ADR、药物警戒、给药错误相关；
- 研究对象是护士、护理人员、护理学生或护理团队；
- 研究干预由护士主导，例如 nurse-led、nurse-managed、nurse follow-up；
- 数据来源或流程与护理记录、护理监测、护理给药、护士上报直接相关；
- 结论解释落在护理实践、护理管理、护理教育或护理工作环境上。

## 对我们下一步设计的含义

### 最稳路径

护理前置主轴：

> 在特定临床场景中，护士的用药安全能力、监测行为、近失/错误上报意愿或护理随访流程，如何影响药物相关风险识别与管理。

可用数据：

- 护士问卷：知识、态度、报告意愿、障碍、用药安全能力；
- 医院护理/不良事件系统：给药错误、近失、ADR 报告、处理流程；
- 护理随访或宣教记录：实验室监测、症状监测、依从性、ADR 恐惧；
- 特定高风险药物：抗凝药、糖皮质激素、抗肿瘤药、精神科药物、抗生素等。

优势：

- 护理身份清楚；
- 近 2 年已有成品论文支持；
- 可以投护理、患者安全、药物安全交叉期刊；
- 不需要把 FAERS 强行解释成护理数据。

### 次稳路径

医院药物警戒项目中的护士报告行为：

> 护士对疑似 ADR 的识别、上报和处理，在医院药物警戒系统中的贡献及影响因素。

优势是 pharmacovigilance 概念最直接；风险是如果只有横断面问卷，创新性偏弱。最好叠加真实上报记录或干预前后设计。

### 高风险路径

FAERS/公开自发报告数据库 + 护理建议：

> 用 FAERS 识别某药物不良事件信号，再讨论护理监测或管理建议。

风险点：

- 近 2 年几乎没有“FAERS + 护理前置”的成熟成品论文；
- 护理变量不在数据库中，护理贡献容易后置；
- 审稿人可能认为这是药物警戒/药物流行病学文章，而不是护理文章；
- 若没有本院护理数据、护理流程或护士行为变量支撑，护理学期刊接受度不确定。

## 建议的具体选题表述

优先建议从这类题目发展：

1. 护士给药近失事件上报意愿及其影响因素：基于三级医院护理工作环境与用药安全能力的研究。
2. 护士主导的高风险药物监测流程对药物相关风险识别的作用：以抗凝药/糖皮质激素/抗肿瘤药为例。
3. 医院药物警戒体系中护士疑似 ADR 上报行为、障碍及改进策略研究。
4. 护理随访记录在药物不良反应早期识别中的价值：真实世界护理数据研究。

当前最推荐的是第 2 或第 3 类：既能保留药物警戒/用药安全交叉属性，又能把护理放在研究设计前台。
