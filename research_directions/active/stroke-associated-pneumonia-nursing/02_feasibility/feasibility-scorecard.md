# 可行性评分卡 (Feasibility Scorecard)

打分标准（1-5分）：
- `1`: 极弱 / 当前阻塞
- `2`: 可能但高风险
- `3`: 可行但存在已知差距
- `4`: 强 / 支撑扎实
- `5`: 极强 / 低风险

| 评估维度 | 得分 (1-5) | 事实依据与说明 |
|---|:---:|---|
| **1. 临床/护理相关性 (Clinical Relevance)** | **5** | 卒中相关性肺炎是神经内科与脑卒中病区最高频、危害最严重的并发症，护理在吞咽、口腔、体位等关键链条中占主导地位，同行关注度极高。 |
| **2. 数据可得性 (Data Availability)** | **4** | 常规 HIS、LIS、护理文书系统（如生命体征记录、洼田饮水试验记录、GCS、Braden、翻身记录）已有现成记录，回顾性提取路径清晰。 |
| **3. 数据质量 (Data Quality)** | **3** | 回顾性数据中，吞咽评估时间节点与部分护理措施执行记录可能存在漏填或粗糙度问题，需建立质控清洗规则。 |
| **4. 样本量合理性 (Sample Size)** | **4** | 卒中单中心年收治量通常在数百至数千例，SAP 发生率约为 10%~20%，满足多因素回归与预测模型建模的基本样本量与事件数（EPV）需求。 |
| **5. 方法可行性 (Method Feasibility)** | **4** | Logistic 回归、Nomogram、倾向评分匹配（PSM）、Cox 风险回归或常规机器学习（Random Forest / XGBoost）方法成熟稳定。 |
| **6. 伦理与治理风险 (Ethics/Governance)** | **5** | 若为单中心回顾性脱敏数据分析，通常可申请免除知情同意（IRB Waiver），审批阻力小。 |
| **7. 文献拥挤与创新度 (Saturation & Novelty)** | **3** | SAP 预测与常规集束化护理已有较多文献，需在“护士专用早期简便指标”、“干预的依从性量化”或“特定亚组（如高龄/重症）”切入以增强创新性。 |
| **8. 期刊匹配度 (Journal Fit)** | **4** | 护理学顶刊及神经科学综合 Q1/Q2 期刊（JCN, JAN, BMC Nursing, Frontiers in Neurology 等）接受度稳定。 |
| **9. 成稿速度 (Speed to Manuscript)** | **4** | 数据提取和清洗完成后，可在 4~6 周内完成统计分析并产出完整手稿。 |
| **综合发表可行性 (Overall Feasibility)** | **4.2 / 5.0** | **高（建议推进，推荐优先聚焦预测模型或真实世界集束化效果）** |
