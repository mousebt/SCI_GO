# 语音+LLM+RAG项目入口

本目录是造影剂不良事件语音辅助报告研究的独立规划项目，不包含程序代码。

## 当前文件

1. `00_project-requirements-and-study-plan.md`  
   完整需求、研究问题、系统流程、候选字段、RAG知识库、提示词原则、评价设计、统计、伦理与论文对应关系。

2. `01_candidate-field-review-form.md`  
   交给护理、影像和药物警戒专家使用的候选字段复核表。

## 使用顺序

1. 研究团队确认需求文档；
2. 专家完成字段复核；
3. 根据专家意见形成最终字段集；
4. 建立标准化病例、参考答案和评分手册；
5. 冻结模型、提示词、知识库和统计方案；
6. 完成离线验证；
7. 如条件允许，再完成护士使用评价；
8. 将真实结果填入论文。

## 论文结论边界

- 只完成需求规划：可写“提出并设计了流程”；
- 完成离线评价：可写“完成初步生成质量验证”；
- 完成护士对照评价且结果支持：方可写“改善报告质量或记录负担”。
