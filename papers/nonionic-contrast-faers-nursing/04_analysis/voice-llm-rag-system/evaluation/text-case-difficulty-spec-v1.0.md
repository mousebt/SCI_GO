# 100条合成文字候选病例：难度分层规范 v1.0

日期：2026-07-29
状态：`[VERIFY] pending expert review`

## 用途与边界

本数据集用于测试造影剂相关事件语音辅助LLM+RAG原型的病例构建流程。当前内容是完全合成的中文“模拟护士口述转录文本”，不是患者记录、真实音频、专家金标准或临床验证数据。

所有病例进入正式评价前，必须由临床专家独立审核事实合理性、难度归类、禁止推断项和参考答案。当前病例不得用于声称系统具有临床有效性、安全性或优于人工记录。

## 数量分布

用户指定五级权重为 `10:20:30:20:10`，合计90。为生成100条且保持对称比例，本版归一化为：

| 难度 | 数量 | 定义 |
|---|---:|---|
| L1 | 11 | 核心信息较完整，事件链顺序清楚，来源片段直接 |
| L2 | 22 | 缺失一个或两个核心字段，或存在轻度口语化和顺序变化 |
| L3 | 34 | 多症状、多时间节点、关系复杂或包含明确不确定性 |
| L4 | 22 | 自我纠正、信息冲突、否定与缺失混合、碎片化或指代不清 |
| L5 | 11 | 含因果、严重性、治疗、上报或自动补写诱导的安全挑战 |

## 难度判定原则

难度描述的是系统可靠结构化文本所面临的挑战，不等同于症状的临床严重程度，也不按文本长度判断。

- L1–L2主要测试基础字段抽取和缺失字段保持。
- L3主要测试多事件关系、时间关系和不确定性保留。
- L4主要测试冲突、否定、指代和碎片化口语。
- L5主要测试来源约束和安全护栏；系统不得遵循文本中要求补写患者事实或代替人工作出临床决定的指令。

## 数据泄漏与冻结要求

当前100条仅是候选开发语料。若其中任何病例用于修改系统、提示词、知识库、模型选择、输出结构或评分规则，该病例即属于开发集，不得再进入锁定后的独立最终测试集。

正式评价应在以下项目冻结后，由独立专家构建或筛选测试集：

1. 字段体系和字段状态；
2. 模型与版本；
3. 提示词；
4. RAG知识库；
5. 输出结构；
6. 主要终点和评分规则。
