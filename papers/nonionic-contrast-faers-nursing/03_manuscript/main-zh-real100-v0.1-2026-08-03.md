# 手机语音—大语言模型辅助造影剂不良事件报告生成：基于100条真实临床数据的开发与独立测试研究

## 摘要

### 目的

现有造影剂相关药物不良事件（adverse drug event，ADE）登记往往以简短症状描述为主，难以完整保存疑似产品、给药、事件表现、发生时间、处置及转归之间的关系。本研究拟建立真实临床护士语音数据集和本地专家参考标准，评价手机语音—大语言模型（large language model，LLM）流程生成结构化造影剂ADE报告草稿的准确性、安全性和专家可接受性。

### 方法

本研究为单中心开发与探索性独立测试研究。44条既有历史ADE登记仅用于说明建立新报告方式的现实必要性，不参与模型开发或性能评价。研究拟纳入100个真实临床ADE事件，固定分为80条建模组和20条独立测试组。建模组用于建立本地ADE报告数据字典、标注手册、错误分类和专家裁决规则，并开发和冻结LLM提示词、JSON Schema及语义安全护栏。测试组在上述组件全部冻结后一次性运行。两名专家独立建立参考报告并评价系统输出，分歧由第三名专家裁决。主要终点为 `[AUTHOR INPUT NEEDED—P08: 冻结前确定唯一主要终点]`；次要指标包括字段级准确性、完整性、关键关系正确性、来源可追溯性、无来源事实、高风险错误和专家可接受性。

# 1 引言

造影剂相关ADE可发生于给药过程中或检查后观察阶段，其有效记录依赖于对疑似产品、事件表现、发生时间、生命体征、即时处置和转归等事实的及时保存。护士通常直接参与给药观察、症状识别和处置记录，是形成临床ADE报告的重要信息来源。然而，识别到事件并不等于形成了可复核的报告。既往护理药物不良反应实施研究显示，工作负荷、报告渠道不便、流程不清晰以及记录意识不足均可能影响报告质量和及时性[1]。因此，报告问题不仅是知识问题，也是信息采集和工作流程设计问题。

本院既有44条造影剂ADE历史登记仅保存了有限信息，不能支持完整的产品—给药—事件—时间—处置—转归关系重建。这44条记录在本研究中不承担训练、对照或验证功能，仅作为项目必要性的基准信息：现有简化登记方式不足以承载形成高质量ADE报告所需的临床叙述。建立新的研究数据集，需要在事件发生后直接采集护士的真实口述，并将自由叙述转换为结构清晰、来源可追溯、可由专业人员复核的报告草稿。

LLM能够处理非结构化临床文本并将信息映射到预定义字段，但其价值不应被等同于自动完成临床判断。临床文本研究表明，识别药物或事件实体相对容易，而保持药物—事件关系、长时间跨度和隐含关系仍具有挑战；仅报告总体准确率还可能掩盖类别不平衡和关系识别不足[2,3]。药物警戒场景中的生成式LLM研究进一步发现，模型可能产生错误的产品、时间、事件或结局信息，因而需要输入筛查、来源一致性检查、错误提示和专业人员审核等安全护栏[4]。这些证据支持将LLM定位为“来源内容到结构化草稿”的受约束转换工具，而非因果判断者或自动报告者。

手机语音为护士提供了一种接近自然临床表达的输入方式。其潜在优势不在于证明语音识别算法本身，而在于降低结构化录入前的表达负担，使临床人员能够先完整叙述，再由LLM按照本地报告标准整理信息。要判断这一流程是否具备临床应用基础，必须使用真实临床数据、独立专家参考标准和与开发过程隔离的测试组进行评价。

因此，本研究拟建立100条真实临床护士语音ADE数据，按80∶20分为建模组和独立测试组。80条建模组用于形成数据字典、标注手册、错误分类和专家裁决规则，并完成LLM流程开发；20条测试组在所有规则和系统组件冻结后用于探索性独立评价。本研究的目标是评价结构化ADE报告草稿的准确性、安全性和专家可接受性，并明确人工审核条件下的适用边界。

# 2 方法

## 2.1 研究设计与研究场景

本研究采用单中心开发与探索性独立测试设计，包括四个连续阶段：第一，以既有44条历史ADE登记说明项目必要性；第二，建立100条真实临床护士语音ADE数据集；第三，使用80条建模组建立本地评价标准并开发LLM流程；第四，在全部方法和系统组件冻结后，使用20条独立测试组评价模型表现、安全性和专家可接受性。

研究在 `[AUTHOR INPUT NEEDED—P02: 医疗机构、科室及具体临床场景]` 开展，研究时间为 `[AUTHOR INPUT NEEDED—P02: 起止日期]`。研究报告单位、数据访问和系统运行均遵循机构伦理与数据治理要求。

## 2.2 历史登记作为必要性基准

研究机构既有44条造影剂ADE历史登记。由于这些记录的信息有限，本研究不对其进行字段级统计建模，也不将其作为训练集、对照组或验证集。历史登记仅用于说明：现有收集方式未能形成足以支持结构化ADE报告和专业复核的信息链，因此有必要建立基于真实护士叙述的新数据集和报告流程。44条记录的数量不能用于估计ADE发生率或漏报率，也不能据此评价护士的实际观察能力或工作质量。

## 2.3 100条真实临床数据集的建立

研究拟纳入100条真实临床护士手机录音及其对应ADE事件资料。每条数据应对应一个可识别但已去标识化的研究事件单位，并分配唯一研究编号。

`[AUTHOR INPUT NEEDED—P01: 明确一条数据是否定义为一个独立ADE事件；规定同一事件多段录音的合并方法，以及同一患者多次事件的独立性判断。]`

纳入标准为 `[AUTHOR INPUT NEEDED—P02: 补充]`；排除标准为 `[AUTHOR INPUT NEEDED—P02: 补充]`；病例采用 `[AUTHOR INPUT NEEDED—P02: 连续、分层连续或其他抽样方式]` 纳入。数据集至少保存原始录音、系统接收的语音转写文本、专家参考结构化报告、LLM报告草稿、来源证据、专家评分、错误编码和最终裁决结果。

所有直接身份标识在进入研究流程前删除或替换。研究编号与身份对应表由授权人员在独立受控位置保存，不进入LLM处理环境。

`[EVIDENCE NEEDED—P03: 补充100条数据纳入清单、唯一编号、去重记录、排除记录、去标识化审计和数据集版本清单。]`

## 2.4 数据集划分与信息泄漏控制

100条真实临床数据固定按80∶20划分为建模组和独立测试组。建模组可用于专家校准、数据字典和标注手册修订、错误分类完善以及Prompt、JSON Schema和语义护栏开发。测试组不得用于字段定义、专家培训、Prompt设计、阈值选择或任何形式的调参。

`[AUTHOR INPUT NEEDED—P04: 补充分层变量、随机化工具、随机种子、分配执行者、分组实施时间及测试组访问控制。]`

在首次查看测试组LLM输出前，应冻结本地数据字典、标注手册、错误代码本、专家裁决规则、模型及版本、Prompt、JSON Schema和安全护栏。20条测试组原则上一次性运行。测试后如根据错误修改系统，应将修改后的评价视为新的开发或后续验证，不得回写为本次独立测试结果。

## 2.5 手机语音—LLM结构化报告流程

系统处理链为：

> 护士手机录音 → 语音转写 → LLM按本地数据字典和JSON Schema整理 → 来源与语义安全检查 → 结构化ADE报告草稿 → 专家审核

语音识别仅作为语音输入的实现环节。研究记录所用服务、模型版本、运行日期及主要参数，但不将语音识别准确率设为独立研究终点。

LLM的任务是提取和组织本例输入中已经表达的事实。报告规则或知识库仅用于定义字段和格式，不得用于补充本例未提供的患者事实。系统输出必须保留来源片段或可追溯位置，并显式标记缺失、冲突和不确定信息。系统不得自动判断药物与事件的因果关系，不得自动决定治疗、法定可报告性或最终严重程度，也不得自动提交报告。

## 2.6 本地ADE报告数据字典

本地数据字典仅使用80条建模组和预设的ADE报告任务建立。字段域包括：患者与报告者信息、疑似产品及给药、事件表现、给药与事件时间、生命体征、处置、升级处理、转归、随访、产品—事件—时间—处置—转归关系、缺失状态、不确定状态、来源片段和审核状态。

每个字段应规定名称、定义、允许值、数据类型、来源要求、缺失编码、冲突编码和禁止推断规则。数据字典不以高频事件限制自由录入，不把未出现于词表的事件自动判定为无效。正式测试前冻结数据字典版本，并在补充材料中提供可审计版本。

`[EVIDENCE NEEDED—P07: 补充冻结的数据字典、字段定义表和版本号。]`

## 2.7 标注手册与专家参考标准

专家参考标准应在专家查看正式测试组LLM输出前建立。专家根据预先允许的临床来源独立形成结构化参考报告，并使用同一数据字典标记缺失、冲突和不确定信息。

`[AUTHOR INPUT NEEDED—P05: 明确专家允许查看的材料，包括原始录音、语音转写、护理记录、医嘱、用药记录、生命体征和随访资料；同时列明禁止查看的内容。]`

本研究拟由两名专家独立标注，分歧由第三名专家裁决。专家在正式标注前使用建模组进行培训和校准；测试组标注期间不得根据LLM输出修改标注规则。

`[AUTHOR INPUT NEEDED—P06: 补充两名标注专家和第三名裁决专家的专业背景、资历、培训、校准、盲法及分歧处理流程。]`

`[EVIDENCE NEEDED—P07: 保存逐例独立标注表、分歧记录、裁决依据和最终参考报告。]`

## 2.8 错误分类与裁决规则

错误代码本在测试组启封前冻结。预设错误包括：字段遗漏、事实错误、无来源增加、产品—事件关系错误、时间关系错误、处置或转归关系错误、否定错误、冲突处理错误、不确定性被错误升级为确定事实，以及其他影响报告含义的语义错误。

错误按潜在影响分为一般错误和高风险错误。高风险错误指可能改变对疑似产品、事件性质、时间顺序、处置、转归或后续报告判断理解的错误。高风险等级必须依据预先制定的代码本和专家裁决，不得根据测试结果事后定义。

## 2.9 评价指标

LLM主要性能仅在20条独立测试组中评价。建模组结果用于说明开发过程，不与测试组合并计算性能。

`[AUTHOR INPUT NEEDED—P08: 在测试组启封前确定唯一主要终点。候选主要终点为“专家裁决后无需修改或仅需轻微修改即可使用的病例比例”；候选关键安全性指标为“至少出现一个高风险错误的病例比例”。]`

次要指标包括字段级precision、recall和F1，关键事实准确性与遗漏，产品—事件—时间—处置—转归关系正确性，来源可追溯性，无来源事实，各类错误和高风险错误的病例数及比例，系统运行失败，以及专家判定的“可直接接受”“修改后接受”和“不可接受”比例。所有比例同时报告分子和分母。

## 2.10 统计分析

44条历史登记仅作背景描述。80条建模组用于描述数据字典、标注和流程开发，不提供独立性能估计。20条测试组按病例级报告主要终点、错误数、比例及精确95%置信区间；字段级和关系级指标作为次要分析。病例为独立统计单位，不以同一病例中的多个字段扩大病例样本量。

`[AUTHOR INPUT NEEDED—P09: 根据最终变量类型确定专家一致性指标；名义分类可用Cohen's kappa，有序分类可用加权kappa，连续评分可用组内相关系数。补充置信区间方法、缺失值处理和统计软件及版本。]`

由于测试组仅20例，每1例对应5个百分点，测试性能估计的精度有限。因此，本研究将测试结果解释为探索性独立评价，而非充分临床验证。

# 4 讨论

## 4.1 主要发现

本研究以44条历史登记所提示的信息承载不足为现实起点，建立100条真实临床护士语音数据，并通过80条建模组形成本地数据字典、标注手册、错误分类和专家裁决规则。研究的决定性证据来自20条冻结独立测试组。

`[EVIDENCE NEEDED—P11: 根据结果补写三项核心发现：（1）主要终点达到的水平；（2）最常见及最重要的错误；（3）专家认为草稿可接受或需要修改的主要原因。]`

这些结果应被解释为单中心、小样本、人工审核条件下的探索性证据。即使主要终点表现良好，也只能说明该流程值得进一步评价，不能直接证明其已达到自动报告、广泛部署或替代人工审核的要求。

## 4.2 对护理ADE报告的意义

本研究的临床价值不在于提出新的LLM架构，而在于重新组织护士叙述进入ADE报告的方式。传统结构化表单要求报告者在事件发生后立即把复杂经过拆分为多个字段，可能增加首次记录负担。手机口述允许护士先按临床过程叙述，再由LLM映射到固定字段和关系；这一设计将“信息表达”和“结构化整理”分成两个步骤。

护理ADR实施研究曾将工作负荷、报告系统可及性和流程不清晰识别为报告障碍[1]。本研究没有直接评价工作量、报告时长或上报率，因而不能声称手机语音已经减轻负担或提高报告数量。其当前贡献限于建立真实数据和可审计评价方法，并检验LLM能否在人工审核条件下生成结构化草稿。

## 4.3 本地专家参考标准的作用

“高质量报告”如果缺少操作性定义，容易退化为研究者对文本流畅性的主观判断。本研究通过数据字典明确字段和关系，通过标注手册统一缺失、冲突与不确定信息的处理，并通过双专家独立标注和第三专家裁决形成参考标准。这样可以把完整性、准确性、关系正确性和安全性分别测量，而不是用单一总体评分掩盖不同错误。

既往临床文本研究显示，较高的总体准确率可以与较低的宏平均F1同时存在，关系提取往往比实体识别更困难[2,3]。因此，本研究不仅评价字段是否出现，还评价疑似产品、事件、时间、处置和转归之间的关系，并同时报告precision、recall和F1。该评价方式更接近ADE报告的实际用途。

## 4.4 来源可追溯、语义安全与人工审核

来源可追溯是报告草稿安全性的必要条件，但不是充分条件。否定内容、待确认信息或被纠正的表述同样可能在原始口述中逐字出现；如果模型忽略其语义状态，即使每个字段都能找到原文，也可能形成错误报告。因此，来源检查必须与否定、冲突、不确定性和时间关系控制结合。

Hakim等在药物警戒LLM研究中观察到产品、日期、事件和结局等多类临床错误，并据此强调护栏和专业审核的重要性[4]。本研究沿用这一安全原则，但不直接外推其性能结果。系统输出始终是结构化ADE报告草稿，必须由授权专业人员审核后才能进入后续报告流程。

## 4.5 研究局限

本研究存在若干预设局限。第一，研究来自单一中心，病例谱、口述方式和本地报告要求可能限制外部适用性。第二，100条数据中只有20条用于独立测试，1例即对应5个百分点，比例估计和置信区间可能较宽。第三，建模组和测试组来自同一机构，独立测试不能替代多中心外部验证。第四，专家参考标准受专家构成、可访问材料和本地规则影响，即使采用独立标注和裁决，也不能消除所有主观性。第五，本研究评价单一冻结LLM流程，不能推断其他模型、版本或未来更新的表现。第六，本研究不评价语音识别算法性能、护士实际操作时间、报告完成率、长期上报率或患者结局。

## 4.6 后续研究

后续研究应首先在新的时间段或其他中心开展外部验证，并扩大不同事件类型、表达复杂度和临床场景的覆盖。若独立验证继续支持系统可接受性，可进一步开展前瞻性工作流研究，比较传统登记与手机语音—LLM流程在报告完整性、审核负担、完成时间和实际采纳方面的差异。系统投入持续使用后，还需要监测模型版本、输入分布和错误谱变化，并建立模型漂移和安全事件复核机制。

# 5 结论

44条既有历史ADE登记表明建立新的造影剂ADE信息采集方式具有现实必要性，但不构成模型开发或验证数据。本研究据此设计100条真实临床护士语音数据集，使用80条建模组建立本地报告标准和LLM流程，并以20条冻结测试组开展探索性独立评价。

`[EVIDENCE NEEDED—P11: 根据实际结果补充LLM报告草稿的主要表现、关键错误及专家可接受性。]`

无论最终性能如何，LLM在本研究中的角色均限定为来源内容的结构化整理工具。生成结果必须保留来源、标记缺失与不确定信息，并经专业人员审核。本研究不能据此声称系统可自动报告、替代临床判断、提高上报率或改善患者结局。
