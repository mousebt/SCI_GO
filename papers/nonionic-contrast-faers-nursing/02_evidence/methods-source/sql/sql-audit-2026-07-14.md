# SQL audit: `单药挖掘最终优化版.sql`

Audit date: 2026-07-14

SHA-256: `4BCA601F8AEC454EC7C2747191B1C5C15BC5E33C811736F688B62C0E5BEA1342`

## What this SQL supports

The script supports the following manuscript methods statements, pending successful database execution and exported results:

- Target drugs are configured as `Ioversol`, `Iohexol`, `Iopamidol`, and `Iodixanol`.
- Study date range is configured as `20040101` to `20251231`.
- Target reports are selected from `drug`, `drug_clean`, and `demo_clean`, using `role_cod = 'PS'`.
- Reporter occupation is filtered to `MD`, `PH`, `OT`, `RN`, and `HP`.
- Adverse events are extracted from `reac.pt`.
- PT-to-SOC mapping is joined through `meddra_soc`, using `pt_name_en` and `soc_name_en`.
- PT/SOC exclusion lists are supported but currently configured as empty JSON arrays.
- The four-cell disproportionality table is constructed as:
  - `a`: target drug + target PT reports.
  - `a+b`: target drug reports.
  - `a+c`: target PT reports in the full database/time window.
  - `a+b+c+d`: all unique reports in the database/time window.
- ROR, ROR lower/upper confidence limits, PRR, chi-square, IC and IC025 are calculated.
- EBGM and an MGPS lower-bound variable named `EB05` are calculated.
- TTO is calculated from `demo_clean.event_dt` and `ther.start_dt`, linked through `primaryid` and `drug_seq`/`dsg_drug_seq`.
- TTO records are kept when both dates match an 8-digit format and `tto_days` is between 0 and 730.

## Issues to fix or document before submission

1. **EBGM05 naming mismatch**
   - The manuscript asks for EBGM/EBGM05.
   - The SQL calculates `EBGM` and `EB05`, and flags `is_mgps_signal` using `EB05 >= 2`.
   - The final output query currently selects `ebgm` but not `EB05` or `is_mgps_signal`.
   - Action: include `EB05 AS EBGM05` and `is_mgps_signal` in the final exported PT/SOC signal tables.

2. **BCPNN/MGPS threshold mismatch in final export**
   - The final signal export filters only `is_ror_signal=1` and `is_prr_signal=1`.
   - It does not filter by `IC025 > 0` or `EB05 >= 2`, although the manuscript methods state four-algorithm criteria.
   - Action: either revise SQL/export criteria to match the manuscript or revise the manuscript to state the actual criteria used.

3. **Single-agent versus pooled analysis**
   - Despite the file name suggesting single-drug mining, the current target list contains all four drugs simultaneously.
   - Action: to generate true agent-specific results, run the script separately for each target drug or add grouping by `drugname`.

4. **Drug dictionary completeness**
   - The script relies on `drug_clean.drugname_clean` matching four generic drug names.
   - Brand names, spelling variants, salts and exclusion rules may already be embedded upstream in `drug_clean`, but they are not visible in this SQL.
   - Action: provide the `drug_clean` construction/cleaning rules or a separate drug dictionary export.

5. **TTO output gap**
   - The SQL creates 0-30, 31-60, 61-90, 91-180 and >180 day groups.
   - It does not directly generate the manuscript's 24-hour statistic, same-day definition, median/IQR or Weibull parameters.
   - Action: add a TTO export for 0 days, <=1 day/24 hours, median/IQR, and Weibull scale/shape with confidence intervals.

6. **Quarter-level download/import inventory**
   - The SQL date range can include 2025 Q4 if the source database contains the quarter, but it does not prove quarter-level download/import completeness.
   - Action: provide a separate FAERS quarter inventory and import log.

7. **Cache dependency**
   - The script depends on `cache_pt_stats_v2`, which must be built by `setup_pt_stats_cache.sql`.
   - Action: archive that setup SQL or document the cache construction method.

## Recommended immediate SQL export columns

For the PT signal table:

`pt, pt_cn, soc, a, b, c, d, ROR, ROR_025, ROR_975, ror_95ci_range, PRR, chi_squared, IC, IC025, EBGM, EB05 AS EBGM05, is_ror_signal, is_prr_signal, is_mgps_signal`

For reproducibility logs:

`step_id, step_info, row_count, log_time`

For TTO:

`tto_days`, plus summary exports for 0 days, <=1 day, 0-30 days, median, Q1, Q3, Weibull scale, Weibull shape and confidence intervals.

- creating pooled plus agent-specific analysis groups;
- exporting `EB05 AS EBGM05`;
- retaining both core ROR/PRR and strict four-algorithm signal flags;
- creating complete PT, strict-positive PT, SOC summary, strict-positive SOC, TTO summary, TTO distribution and raw TTO export statements;
- preserving raw `tto_days` for external Weibull modelling.
